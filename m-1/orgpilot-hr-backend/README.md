# OrgPilot HR backend

Backend-only package. Start with backend/README.md for setup, APIs and AI integration.

From this directory:

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python backend/manage.py test hr
python backend/manage.py runserver 127.0.0.1:8000
```

Includes source CSVs and backend documentation. No frontend code, installed dependencies, secrets, or Git history is included.
